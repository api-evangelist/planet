# Planet

> Planet Labs PBC operates the largest constellation of Earth-imaging satellites, capturing a daily scan of the planet's landmass and delivering imagery, Planetary Variables, and analytics through a suite of public developer APIs served from api.planet.com. Authentication is by API key (HTTP Basic) or OAuth2/OIDC via login.planet.com. This llms.txt was generated by API Evangelist from the Planet developer documentation and catalog artifacts.

## APIs

- [Planet Data API](https://docs.planet.com/develop/apis/data/): Search Planet's imagery catalog by geometry, date, and cloud cover; discover items and downloadable assets (base: https://api.planet.com/data/v1)
- [Planet Orders API](https://docs.planet.com/develop/apis/orders/): Request downloads and cloud delivery of imagery with raster/band tools
- [Planet Subscriptions API](https://docs.planet.com/develop/apis/subscriptions/): Continuous cloud delivery of new imagery and Planetary Variables
- [Planet Basemaps API](https://docs.planet.com/develop/apis/basemaps/): Access and download global and regional basemap mosaics
- [Planet Tasking API](https://docs.planet.com/develop/apis/tasking/): Command SkySat and Pelican satellites to capture new imagery
- [Planet Features API](https://docs.planet.com/develop/apis/features/): Save and reuse areas of interest across the platform
